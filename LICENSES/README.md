# QSOL-ARK License Map

QSOL-ARK is intentionally dual licensed by file class.

## Apache License 2.0

Applies to software and executable material, including source code, scripts, command-line tools, adapters, test harnesses, executable examples, and build/CI code unless a file states otherwise.

The root `LICENSE` contains the Apache License 2.0 text.

SPDX identifier: `Apache-2.0`

## Creative Commons Attribution 4.0 International

Applies to original non-software content produced for QSOL-ARK, including documentation, benchmark specifications, schemas, manifests, original substrate/context records, original datasets, and explanatory material unless a file states otherwise.

SPDX identifier: `CC-BY-4.0`
Canonical license: `https://creativecommons.org/licenses/by/4.0/`

## Third-party material

Third-party material retains its original copyright and license. Import manifests must identify source and license explicitly. QSOL-ARK does not relicense material it does not own merely by including or referencing it.

## Precedence

A file-specific license notice or imported-artifact manifest overrides the default class mapping for that file/artifact.
