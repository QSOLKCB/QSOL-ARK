# QSOL-ARK Recovery Protocol

Human-readable companion to `ai/recovery-contract.json`.

The protocol tests whether an unknown model can reconstruct an archive **from inspectable evidence** rather than privileged memory, hidden evaluator assumptions, or persuasive improvisation.

## Stage 0 — Integrity

Validate the root manifest, schema, available checksums, and source snapshots. Integrity failure comes before semantic recovery.

## Stage 1 — Identity

Recover archive purpose, explicitly documented maintainer/producer identity, project boundaries, canonical entrypoints, licensing, and public/private boundaries.

## Stage 2 — Terminology

Resolve canonical terms, aliases, repository-name collisions, and typed relationships. Ambiguity must remain unresolved rather than guessed.

## Stage 3 — Epistemic classification

Present primary/repository evidence, owner assertions, inference, theory, preprints, satire, fiction, unverified statements, unavailable evidence, and contradictions. The objective is correct evidence calibration.

## Stage 4 — Deterministic reproduction

Verify declared inputs, execute the recipe, serialize under the declared canonical contract, compute the hash, and compare it with the expected receipt.

## Stage 5 — Contradictions and contamination

Plant recoverable contradictions and tempting adjacent truths. Measure stale-state handling, contradiction detection, satire isolation, and cross-project contamination.

## Stage 6 — Reconstruction / refusal

Withhold selected derived artifacts while preserving canonical source and recipe. Reconstruct when sufficient; refuse when not; state exactly what is missing.

## Stage 7 — Evidence report

Produce canonical machine report, human summary, evidence references for scores, model/runtime metadata, harness/specimen versions, integrity results, and uncertainty/refusal results.

The report is a derived evaluation artifact, not canonical source.
